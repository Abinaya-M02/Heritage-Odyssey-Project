# 🏛️ Heritage Odyssey Project

An Indian Heritage Information System built using **Python, Flask, HTML, CSS, JavaScript, and MySQL**.

## 📖 About

Heritage Odyssey Project is a web application that helps users explore and discover India's rich cultural heritage — including temples, palaces, forts, tombs, valleys, waterfalls, and wildlife sanctuaries.

## ✨ Features

- 🔍 Search functionality to find heritage sites easily
- 🗂️ Browse places by category (Temples, Palaces, Forts, Tombs, Valleys, Waterfalls, Wildlife)
- 📄 Detailed information page for each heritage site
- 🔐 User login system
- 📱 Responsive and user-friendly design

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/Abinaya-M02/Heritage-Odyssey-Project.git
   ```
2. Install the required dependencies
3. Set up your MySQL database
4. Run the Flask application
   ```bash
   python app.py
   ```
## 📌 Note

Currently, each category (Temples, Palaces, Forts, etc.) contains 10 heritage places. More places will be added in future updates.
