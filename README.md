# 🏛️ Heritage Odyssey Project
An Indian Heritage Information System built using **Python, Flask, HTML, CSS, JavaScript, and MySQL**.

## 📖 About
Heritage Odyssey Project is a web application that helps users explore and discover India's rich cultural heritage — including temples, palaces, forts, tombs, valleys, waterfalls, and wildlife sanctuaries etc,.

## ✨ Features
- 🔐 User sign up and login system
- 🔍 Search functionality to find heritage sites easily
- 🖼️ Card-based UI to display heritage places with images
- 📄 Detailed information page for each heritage site
- 📱 Responsive and user-friendly design

## 🗂️ Categories
Places are organized under three main heritage types:
- **🛕 Religious Heritage** – Temples, Churches, Mosques, Gurudwaras, Monasteries
- **🏰 Historical Heritage** – Forts, Palaces, Monuments, Tombs
- **🌿 Natural Heritage** – Valleys, Waterfalls, Wildlife Sanctuaries

Each sub-category showcases curated heritage places with images and details.
## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL

## 🚀 Getting Started
1. Clone the repository
   git clone https://github.com/Abinaya-M02/Heritage-Odyssey-Project.git
2. Install the required dependencies
3. Set up your MySQL database
4. Run the Flask application
   python app.py
